# KIDO Employee Lifecycle Workflow Tracker

A workflow tracking application for managing the full employee lifecycle — from onboarding through offboarding.

## Overview

KIDO Employee Lifecycle Workflow Tracker helps organizations manage and automate employee lifecycle processes including:

- **Onboarding** — New hire setup, document collection, training assignments
- **Role Changes** — Promotions, transfers, department changes
- **Leave Management** — Leave requests, approvals, return-to-work processes
- **Offboarding** — Exit interviews, asset collection, access revocation

## Getting Started

### Prerequisites

- Node.js >= 18
- npm >= 9

### Installation

```bash
npm install
```

### Running the Application

```bash
npm start
```

### Running Tests

```bash
npm test
```
